# 嘉信实时翻译 SchwabTranslate

给嘉信（Charles Schwab）App 用的实时翻译：录屏时识别画面里的英文，翻成中文，半透明盖在原来文字的位置上。

## 两种用法

**实时翻译（录屏）**
1. 打开嘉信 App，到要翻译的页面。
2. 从右上角下拉打开控制中心，长按“屏幕录制”。
3. 选择 SchwabTranslate，点“开始直播”。
4. 切回本 App，最新一帧的译文会盖在原文位置上（扩展每 1.5 秒抓一帧）。
5. 用完在控制中心点红色条停止录屏。

**截图翻译**
截一张嘉信 App 的图，在“截图翻译”里选图，识别完直接看。

## v1.2 改了什么：画中画悬浮窗

新增“画中画”页，译文可以浮在嘉信 App 上面，不用再切回本 App 看：

1. 在本 App 点“画中画”页的“开始画中画”，窗口先浮出来，显示“等待录屏开始”。
2. 点页里的录屏按钮（或控制中心长按屏幕录制），选 SchwabTranslate 开始直播。
3. 去嘉信 App，画中画窗口浮在上面，拖到想看的位置，译文一句一句显示。
4. 用完先停直播，再点“停止画中画”。

技术：录屏扩展把译文推给本 App 的本机服务（127.0.0.1:8765，未签名包没有 App Groups 权限，剪贴板做备用通道）；本 App 把译文句子画成一张文本卡片，用 `AVSampleBufferDisplayLayer` + `AVPictureInPictureController`（iOS 15+ 自定义内容源）推到画中画窗口，不用 AVPlayer、不用转码。窗口里只显示译文句子，不显示屏幕画面，所以录屏不会把窗口自己拍进去。App 靠音频后台模式 + 播放会话在后台存活，推流服务才能一直被扩展找到。

**v1.2 实验版，手机上还没验证过**：画中画能不能正常弹出来、后台会不会被系统杀掉、窗口会不会变黑，都要装上手机实测才知道。

## v1.1 改了什么

- **悬浮窗模式**：实时翻译页点“悬浮窗”，全屏只剩画面和译文，没有导航栏和按钮挡着，右上角一个小叉退出，底部可以切原文/译文。
- **框不易掉**：连续几帧之间框的位置会稳住（中心点没动就沿用上一帧的框），偶尔一两帧没识别出来也先留着上一帧的框；抓帧从 1.5 秒一帧提到 1 秒一帧。
- **不和原文重叠**：每处译文是接近不透明的黑底卡片，框比识别到的文字稍大，把原来的黑白字完全盖住，不出重影。

## 技术

- 录屏：ReplayKit Broadcast Upload Extension（`SchwabTranslateBroadcast`）
- 识别：本机 Vision OCR（英文，accurate 模式）
- 翻译：Google 免费接口（`translate.googleapis.com`，不需要 key，需要联网）
- 扩展和主 App 之间用系统剪贴板传数据（未签名包没有 App Groups 权限）

## 实话实说：做不到的事

- v1.2 的画中画是系统 PiP 窗口，不是真的在别的 App 上画字，窗口大小和位置由系统管，只能拖、不能改大小；窗口里是译文句子列表，不是原位置覆盖。手机上还没验证过，能不能弹出来、后台会不会掉，都要实测。
- 翻译要联网；断网时只能识别原文。
- 录屏扩展内存有限，抓帧频率不高，画面切太快会漏帧，等 1–2 秒刷新。
- 未编译验证前都是实验版：以 Codemagic 构建结果为准，装上手机实测才算数。
